# Founders NFT Metadata & Traits

The Founders NFT follows the Metaplex Token Metadata standard on Solana.

## Metadata Structure

Each NFT includes the following core fields:

- **Name**: `Fantasy Slab Founder #XXX`
- **Symbol**: `FSF`
- **Description**: Grants the holder a share of platform revenue through weekly on-chain airdrops.
- **Image**: Hosted on Arweave for permanence

## Traits

| Trait Type            | Value                  | Description |
|-----------------------|------------------------|-----------|
| **Tier**              | Founder                | Fixed for all 100 |
| **Generation**        | Genesis                | Indicates first collection |
| **Revenue Share**     | 0.8%                   | Individual revenue share |
| **Airdrop Frequency** | Weekly                 | Sunday 00:00 UTC |
| **Access Level**      | Priority               | Early access to drops and features |
| **Special Perk**      | Governance / Slab Priority | Varies by token |
| **Founding Year**     | 2026                   | Historical marker |

## Standards

- Built using **Metaplex Token Metadata**
- Hosted on **Arweave** for long-term permanence
- Uses **Programmable NFT** standard for future extensibility
